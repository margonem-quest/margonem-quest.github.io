# Margonem Quest Helper

Prosta, statyczna strona do tworzenia własnej bazy questów.

## Uruchomienie

1. Rozpakuj pliki.
2. Otwórz `index.html` w przeglądarce.
3. Gotowe.

## Funkcje

- wyszukiwanie questów,
- filtrowanie po poziomie,
- widok kroków questa,
- oznaczanie wykonanych kroków,
- zapis postępu w `localStorage`,
- dodawanie własnych questów,
- jasny i ciemny motyw.

## Ważne

Dane przykładowych questów są demonstracyjne. Projekt nie pobiera automatycznie danych z Margonem.

To nieoficjalny projekt fanowski.
